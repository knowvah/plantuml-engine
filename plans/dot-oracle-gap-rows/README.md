## Stop conditions (halt, journal, report)

1. A conformant row in any engine, or a pinned dot golden, leaves conformant, and you cannot state its mechanism with
   `file:line`.
2. A pinned golden would have to be re-captured or removed, or a pinned error-page score would have to rise.
3. The same gate fails on 2 consecutive fix attempts.
4. A finding contradicts D1 to D6. Amend `decisions.md` with the date, then halt.
5. Any `dist/*.d.ts` change. No public type should move (D5).
6. A fix for the 2 structural rows needs a write to `@knowvah/dot-engine`, `~/git/graphviz` or `~/git/plantuml`
   (CLAUDE.md, "Writing and write-sets"). File the finding instead (D4); do not work around it in this repo by fitting.

**These are not stops:**
- A file outside a task's write-set inside this repository. Change it and journal why.
- A row whose fix needs a maintainer ruling (a new divergence, such as host font metrics the browser cannot have).
  File a `needs-ruling` issue with the evidence, name the row in the journal, and continue. Do not decide it here
  (#141, "Done when").
- A residual diff that a fix uncovers, provided its mechanism is the task's. Fix it in the same task.
